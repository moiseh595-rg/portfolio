# Moise Hector — Portfolio

Minimal dark portfolio built with HTML, CSS and JavaScript.

## Structure

- `index.html` — Home
- `work.html` — Projects
- `about.html` — About
- `cv.html` — Website CV
- `contact.html` — Contact
- `projects/` — Individual project case studies
- `css/` — Global, responsive and animation styles
- `js/` — Navigation and interactions
