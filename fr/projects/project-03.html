RUBIK’S CUBE

01 / PRÉSENTATION

PRÉSENTATION DU PROJET

Le sujet consiste à représenter un Rubik’s Cube 3×3 en Java, à programmer ses mouvements puis à progresser vers un algorithme de résolution automatique. Le projet met en pratique les fondamentaux de la programmation Java.

L’OBJECTIF

Traduire les règles d’un cube physique dans un programme structuré, en utilisant des tableaux, des méthodes, des boucles et des algorithmes pour représenter et modifier son état.

02 / ARCHITECTURE

COMMENT LE CUBE EST REPRÉSENTÉ

03 / JAVA

UN APERÇU DU JAVA

Deux courts exemples de référence illustrent l’approche prévue. Ils seront remplacés par mon code personnel vérifié.

01 / INITIALISATION DU CUBE

Création du cube

RCPartie1.java · EXEMPLE DE RÉFÉRENCE
int[][][] creerRubikCubeVierge() {

    int[][][] cube = new int[6][3][3];

    for (int face = 0; face < 6; face++) {

        for (int ligne = 0; ligne < 3; ligne++) {

            for (int colonne = 0; colonne < 3; colonne++) {

                cube[face][ligne][colonne] = face;

            }

        }

    }

    return cube;

}

Chaque face reçoit sa propre couleur (indice 0 à 5). Trois boucles parcourent les faces, les lignes et les colonnes.

02 / ROTATION D’UNE FACE

Rotation horaire

RCPartie1.java · EXEMPLE DE RÉFÉRENCE
void pivoterFace(int[][] face) {

    int[][] copie = new int[3][3];

    for (int i = 0; i < 3; i++) {

        for (int j = 0; j < 3; j++) {

            copie[i][j] = face[i][j];

        }

    }

    for (int i = 0; i < 3; i++) {

        for (int j = 0; j < 3; j++) {

            face[i][j] = copie[2 - j][i];

        }

    }

}

Une copie évite d’écraser les valeurs pendant le quart de tour. La formule replace chaque case dans sa nouvelle position.

05 / ALGORITHMES

MOUVEMENTS ET RÉSOLUTION

Le projet comporte deux étapes : manipuler le cube et annuler un mélange enregistré, puis concevoir une résolution sans connaître les mouvements précédents.

PARTIE 01 / MÉMORISATION

Inverser le mélange

La première partie consiste notamment à inverser une suite de mouvements enregistrés.

PARTIE 02 / RÉSOLUTION AUTOMATIQUE

Résoudre sans historique

La deuxième partie vise une résolution automatique sans historique. Le résultat sera présenté une fois implémenté et vérifié.
