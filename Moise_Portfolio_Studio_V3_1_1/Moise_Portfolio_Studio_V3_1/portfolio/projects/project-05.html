MONETA

A personal finance app that feels calm instead of overwhelming — built to be easy to understand, with clear visuals around every number.

13development stages reached
2languages: English & French
3themes: light, dark, system
PWAinstallable on phone & desktop
THE GOAL

Money should be easy to read.

Most finance tools bury people in numbers. MONETA is my attempt at the opposite: a bank-app level of polish, with gauges, bars and rings so a user understands their situation at a glance, and with as little manual input as possible.

WHAT IT DOES

Everything in one calm space.

01

Accounts & activity

Several accounts, balances, transfers and a full history. Transfers never count as income or spending.

02

Budgets & schedules

Monthly category budgets shown as gauges, plus recurring bills and subscriptions with upcoming-payment reminders.

03

Goals & Insights

Savings goals with progress rings and Insights that explain exactly what each figure includes.

04

Shopping & prices

Shopping lists and recorded prices compared fairly by unit, linked to expenses without counting a purchase twice.

05

Privacy & reliability

Each user only sees their own data. Duplicate-save protection, offline handling and expired-session handling.

06

Your data

Profile and preferences, JSON/CSV export and an account-deletion workflow.

THE INTERFACE

Premium on desktop and phone.

The interface uses a navy, lavender and mint palette, layered surfaces, readable contrast in light and dark mode, and a mobile bottom bar. These screenshots use fictional demo data.

UNDER THE HOOD

Technology.

Frontend

Vanilla JavaScript, HTML and CSS — no framework, with a custom premium design system.

Backend

Supabase: authentication, PostgreSQL database and row-level security so users are isolated.

Quality

Automated browser and database tests for balances, transfers, isolation and duplicate saves.

Delivery

Progressive Web App with offline support, and a production build prepared for free hosting.

LEARNED

Challenges and lessons.

Early on I lost direction: I built features without a fixed scope, and fixes kept breaking other areas. I changed my process — define the full checklist for each stage first, build one cumulative package, then test. I also learned the difference between “implemented” and “verified”: a button existing in code is not proof that the whole workflow works.

STATUS

Honest status.

MONETA is under active development and has been tested locally. Production validation is still pending. It is not published yet: the database runs on Supabase and the app runs from the project code. The next steps are free hosting, real email checks and testing with real users.
