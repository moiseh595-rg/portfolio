# Portfolio media

## Profile
Put the final professional portrait in:
`images/profile/`

Recommended filename:
`moise-hector.jpg`

## Projects
Each project should eventually have its own folder:
- `images/projects/chuck-norris/`
- `images/projects/linux-workstation/`
- `images/projects/java/`

Put screenshots, diagrams and final result images in the matching folder.

## Videos
Put short project demonstrations in:
`videos/projects/`

Recommended format: MP4 (H.264), kept reasonably compressed.

## Important
Do not use random stock images for academic projects. The portfolio should show evidence of your actual work.
