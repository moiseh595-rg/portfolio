01 / PRÉSENTATION

PRÉSENTATION DU PROJET

Ce projet universitaire explore la représentation d’un Rubik’s Cube 3×3, la programmation de ses mouvements et la résolution automatique. La version Java publiée comprend les opérations sur le cube, les séquences de mouvements et une recherche limitée de solutions courtes.

L’OBJECTIF

Traduire les règles d’un cube physique dans un programme structuré, en utilisant des tableaux, des méthodes, des boucles et des algorithmes pour représenter et modifier son état.

03 / JAVA

UN APERÇU DU JAVA

01 / INITIALISATION DU CUBE

Création du cube

JAVA · MATRIX OPERATIONS 
int[][][] creerRubikCubeVierge() {

    int[][][] cube = new int[6][3][3];

    for (int face = 0; face < 6; face++) {

        for (int ligne = 0; ligne < 3; ligne++) {

            for (int colonne = 0; colonne < 3; colonne++) {

                cube[face][ligne][colonne] = face;

            }

        }

    }

    return cube;

}

Chaque face reçoit sa propre couleur (indice 0 à 5). Trois boucles parcourent les faces, les lignes et les colonnes.

02 / ROTATION D’UNE FACE

Rotation horaire

JAVA · MATRIX OPERATIONS 
void pivoterFace(int[][] face) {

    int[][] copie = new int[3][3];

    for (int i = 0; i < 3; i++) {

        for (int j = 0; j < 3; j++) {

            copie[i][j] = face[i][j];

        }

    }

    for (int i = 0; i < 3; i++) {

        for (int j = 0; j < 3; j++) {

            face[i][j] = copie[2 - j][i];

        }

    }

}

Une copie évite d’écraser les valeurs pendant le quart de tour. La formule replace chaque case dans sa nouvelle position.

05 / ALGORITHMES

MOUVEMENTS ET RÉSOLUTION

Le projet relie les rotations, les séquences de mouvements et le problème de la résolution à partir de l’état actuel du cube.

PARTIE 01 / MÉMORISATION

Inverser le mélange

Une séquence enregistrée peut être inversée en parcourant les mouvements dans l’ordre inverse et en inversant chaque rotation.

PARTIE 02 / RÉSOLUTION AUTOMATIQUE

Résoudre sans historique

La version Java publiée recherche des solutions pour de courts mélanges à partir de l’état actuel du cube, sans utiliser l’historique. Le sujet présente également une stratégie de résolution plus générale, couche par couche.
