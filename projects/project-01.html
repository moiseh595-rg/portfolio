OBJECTIVE

The objective of this academic project is to create a multi-page website about Chuck Norris using HTML5 and CSS3, following the exercises and instructions provided during our web development classes.

The project covers website structure, navigation, CSS styling, tables, page layouts, HTML forms and responsive design for different screen sizes.

While following the required structure and techniques, I can also choose my own colors and visual style.

PROCESS

01 — HTML STRUCTURE (TD1)
Created the basic HTML5 document using headings, paragraphs, lists, links, images and anchors. Learned how to organize the content of a web page.

02 — CSS STYLING (TD2)
Used an external CSS stylesheet to customize colors, fonts, dimensions and text alignment. Practiced CSS selectors, classes, IDs and specificity.

03 — PAGE ORGANIZATION (TD3)
Organized the website using semantic HTML elements such as header, nav, main, article, aside and footer. Added a contact page, a comparison table and worked with the CSS box model.

04 — LAYOUT (TD4)
Worked with display properties, Flexbox, float and CSS positioning to organize the page. Practiced navigation menus, dropdowns and hover effects.

05 — HTML FORMS (TD5)
The next stage will focus on creating an HTML form with text inputs, radio buttons, checkboxes, select menus and textareas. It will also introduce field validation and sending form data.

06 — RESPONSIVE DESIGN (TD6)
The final stage will focus on adapting the website to different screen sizes using flexible dimensions, media queries and Flexbox. It will also introduce a mobile navigation menu.

WHAT I LEARNED

This project has helped me understand how HTML and CSS work together to build and style web pages.

I have practiced semantic HTML, CSS selectors, specificity, the box model, positioning and different layout techniques.

I have also learned how to inspect a web page using browser developer tools and identify problems in HTML and CSS code.

The remaining lessons will help me develop my skills in HTML forms, input validation, responsive layouts and mobile navigation.
