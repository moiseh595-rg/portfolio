01 / CUBE INITIALIZATION

Creating the cube

RCPartie1.java · REFERENCE EXAMPLE
int[][][] creerRubikCubeVierge() {

    int[][][] cube = new int[6][3][3];

    for (int face = 0; face < 6; face++) {

        for (int row = 0; row < 3; row++) {

            for (int col = 0; col < 3; col++) {

                cube[face][row][col] = face;

            }

        }

    }

    return cube;

}

Each face receives its own color index (0–5). Three loops traverse the faces, rows, and columns.

02 / FACE ROTATION

Clockwise rotation

RCPartie1.java · REFERENCE EXAMPLE
void pivoterFace(int[][] face) {

    int[][] copie = new int[3][3];

    for (int i = 0; i < 3; i++) {

        for (int j = 0; j < 3; j++) {

            copie[i][j] = face[i][j];

        }

    }

    for (int i = 0; i < 3; i++) {

        for (int j = 0; j < 3; j++) {

            face[i][j] = copie[2 - j][i];

        }

    }

}

A temporary copy prevents overwriting values during rotation. The index formula places each sticker in its new position.
